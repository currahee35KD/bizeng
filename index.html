初回セットアップ
現在のURL：
  1. Google Cloud でプロジェクト作成
  2. Drive API を有効化
  3. Google Auth Platform → 開始 → 対象は外部
  4. 「対象」で自分のGmailをテストユーザーに追加
  5. 「クライアント」→ 作成 → ウェブアプリケーション
  6. 承認済みJavaScript生成元に上のURLを貼る
  7. クライアントIDを下に貼り「保存」→「今すぐ同期」

AI生成・AI添削の接続

未接続でも内蔵フレーズの学習と発話採点は使えます。 接続すると2〜3文の説明や会話モード、発話のAI添削が使えるようになります。

aistudio.google.com/apikey でキーを作成 → 貼り付け →「使えるモデルを検出」→「接続テスト」。
OpenAIは事前入金が必要です。CORSで失敗する場合はGeminiをお使いください。
