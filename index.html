この学習法の根拠

Google Drive 同期

この開き方では同期できません
Googleは認証を許可する場所をURLで登録する必要があり、file:// は登録できません。 GitHub Pages に置いてURLで開いてください。

当面は下部のエクスポート／インポートで手動移行できます。
初回セットアップ
現在のURL：
  1. Google Cloud でプロジェクト作成
  2. Drive API を有効化
  3. Google Auth Platform → 開始 → 対象は外部
  4. 「対象」で自分のGmailをテストユーザーに追加
  5. 「クライアント」→ 作成 → ウェブアプリケーション
  6. 承認済みJavaScript生成元に上のURLを貼る
  7. クライアントIDを下に貼り「保存」→「今すぐ同期」
保存先はDriveのアプリデータフォルダ。既存ファイルにはアクセスしません。
2台で学習してもカードと履歴は統合されます。
