この学習法の根拠

AI生成の接続（任意）

未設定でも、内蔵の195フレーズから場面に合わせて生成します。 キーを入れると、どんな場面でも新規に作れます。キーはこの端末内にのみ保存されます。

取得手順
  1. aistudio.google.com/apikey を開く
  2. 「APIキーを作成」→ 一覧の行のコピーアイコンで全文をコピー
  3. 下に貼り付け →「使えるモデルを検出」→「接続テスト」
無料枠のまま使えます。お支払い情報の設定は不要です。
OpenAIは事前入金が必要です。一部の互換エンドポイントはブラウザから直接呼べません（CORS）。 失敗する場合はGeminiをお使いください。

Google Drive 同期

この開き方では同期できません
Googleは認証を許可する場所をURLで登録する必要があり、ファイルを直接開いた状態（file://）は登録できません。 GitHub Pages などに置いて、URLで開いてください。 そうすればPC・スマホどこからでも同じURLで使えます。

当面はこのページ下部のエクスポート／インポートで手動移行できます。
初回セットアップ
現在のURL：
この値をGoogle側に登録します。
  1. Google Cloud でプロジェクトを作成
  2. Google Drive API を「有効にする」
  3. 「APIとサービス」→「OAuth同意画面」を設定（User type は外部、自分のGoogleアカウントをテストユーザーに追加）
  4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類はウェブアプリケーション
  5. 承認済みのJavaScript生成元に上のURLを貼り付けて作成
  6. できたクライアントIDを下に貼り付けて「保存」→「今すぐ同期」
保存先はDriveのアプリデータフォルダ（このアプリ専用の隠し領域）です。 ドライブ画面には出ず、他のアプリからは読めません。あなたのファイルへのアクセス権は要求しません。
両方の端末で学習していても、カードと履歴は統合されます（学習が進んでいる方を採用）。上書きで消えることはありません。
