Google Drive 同期

この開き方では同期できません
Googleは認証を許可する場所をURLで登録する必要があり、ファイルを直接開いた状態（file://）は登録できません。 GitHub Pages などに置いてURLで開いてください。

当面は下部のエクスポート／インポートで手動移行できます。
初回セットアップ
現在のURL：
  1. Google Cloud でプロジェクト作成
  2. Google Drive API を有効化
  3. 「Google Auth Platform」→ 開始 → 対象は外部
  4. 「対象」ページで自分のGmailをテストユーザーに追加
  5. 「クライアント」→ 作成 → 種類はウェブアプリケーション
  6. 承認済みのJavaScript生成元に上のURLを貼る
  7. できたクライアントIDを下に貼り「保存」→「今すぐ同期」
保存先はDriveのアプリデータフォルダ（専用の隠し領域）です。あなたの既存ファイルにはアクセスしません。
2台で学習しても、カードと履歴は統合されます。上書きで消えません。

AI生成の接続（任意）

未設定でも内蔵フレーズで学習できます。キーを入れると、どんな場面でも新規に作れます。

aistudio.google.com/apikey でキーを作成 → 下に貼り付け →「使えるモデルを検出」→「接続テスト」。無料枠のままで使えます。
OpenAIは事前入金が必要です。互換エンドポイントはブラウザから直接呼べない場合があります（CORS）。
